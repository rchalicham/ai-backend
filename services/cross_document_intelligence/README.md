# Cross-Document Intelligence Framework

`cross_document_intelligence` is the deterministic, non-authoritative enterprise
context sidecar after the Enterprise Knowledge Graph.

It resolves canonical identities across independent graph snapshots, links
documents only when supported by evidence, constructs evidence-referencing
timelines, correlates semantic relationships, detects historical patterns and
anomalies, and exposes storage-neutral longitudinal queries and explanations.

Enterprise Memory contains versioned normalized entities, relationships,
timelines, evidence, patterns, and correlations. It is deterministic semantic
memory—not LLM memory, source-document storage, graph storage, machine
learning, or prediction.

Runtime evaluation reads approved memory when supplied and performs no
automatic repository write. Patterns are detection only, anomalies are
diagnostics only, and learning outputs require approval. No document, graph,
Business Fact, extraction result, or parser behavior is modified.
